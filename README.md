# Coolest Art — make.fun entry (coolest-art-01)

A colossal blue whale flying over a moonlit fjord village at night,
a glowing waterfall of light beneath it, a full moon behind snowy
mountains and warm lit wooden houses below. Generated by the entrant
with Stable Diffusion XL on their own PC, refined with img2img, and
saved as a 1024×1024 JPEG.

`main.py` (Python 3.13, standard library only) copies the picture held in
this repository (`entry.jpg`, 1024×1024 JPEG, 292,784 bytes) to
`/output/entry.png`. The program is deterministic: running it twice writes
byte-identical output.

## Run locally

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
