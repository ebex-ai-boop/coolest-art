# Coolest Art — make.fun entry (coolest-art-01)

A giant golden eye floating alone in a deep indigo void, its iris
reflecting a swirling galaxy — seeing the universe within oneself.
Generated by the entrant with Stable Diffusion XL on their own PC and
saved as a 1024×1024 JPEG.

Round 2 replaces the round-1 whale: the whale scored 82.63% in the dev
heats, and the judge's own notes said its moon/village/waterfall stack
was too busy and lost clarity at small size. This entry answers that
directly — one dominant subject, a clean dark background, bold gold
against indigo, readable at a glance.

`main.py` (Python 3.13, standard library only) copies the picture held in
this repository (`entry.jpg`, 1024×1024 JPEG, 309,374 bytes) to
`/output/entry.png`. The program is deterministic: running it twice writes
byte-identical output.

## Run locally

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
