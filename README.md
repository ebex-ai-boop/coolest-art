# Coolest Art — make.fun entry (coolest-art-01)

A lone surfer riding a giant curling wave beneath a starry sky — a
human silhouette on the crest of a cosmic wave, gold starlight on
deep indigo water. Generated by the entrant with Stable Diffusion XL
on their own PC and saved as a 1024×1024 JPEG.

Round 3 replaces the round-2 eye: the eye scored 90.25% in the dev
heats, and the judge's own notes said the "cosmic eye" was a familiar
AI-art staple, "one visual note and no narrative", and "more static"
than the entries that beat it — a stained-glass koi won on story and
a synthwave tiger won on dynamic energy. This entry answers that
directly: a fresh concept with a story (a lone rider on a wave of
stars), a dynamic pose, one clear silhouette, and a unified
indigo-and-gold mood that still reads at a glance.

`main.py` (Python 3.13, standard library only) copies the picture held in
this repository (`entry.jpg`, 1024×1024 JPEG, 326,577 bytes) to
`/output/entry.png`. The program is deterministic: running it twice writes
byte-identical output.

## Run locally

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
